# Pattern: ATS Optimization

## When to Apply

- Targeting large companies with automated screening
- Submitting through job boards (LinkedIn, Indeed, etc.)
- ATS-heavy hiring pipelines (enterprise, high-volume roles)
- Resume needs to pass machine parsing before human review

## Approach

1. Use standard section headers that ATS systems recognize
2. Optimize keyword density for target role/industry
3. Simplify formatting (avoid tables, columns, graphics)
4. Include full job titles and company names
5. Spell out acronyms on first use
6. Use standard date formats (Month Year - Month Year)

### Standard Section Headers

| Use                     | Avoid                  |
| ----------------------- | ---------------------- |
| Professional Experience | Where I've Made Impact |
| Skills                  | My Toolkit             |
| Education               | Learning Journey       |
| Professional Summary    | Who I Am               |
| Technical Skills        | Tech Stack             |

### Keyword Optimization

- Mirror exact phrases from job description
- Include both acronyms and full terms (e.g., "CI/CD (Continuous
  Integration)")
- List specific technologies by name, not categories
- Include industry-standard certifications if held

## Example Transformations

**Creative:**

> **Where I've Made Impact**
>
> Led the charge on modernizing our component architecture, bringing
> fresh eyes to stale patterns.

**ATS-Optimized:**

> **Professional Experience**
>
> Led React component library modernization, implementing design system
> architecture and improving developer productivity by 40%.

---

**Informal:**

> Built cool stuff with Node, React, and all the usual suspects.

**ATS-Optimized:**

> Built production applications using Node.js, React, TypeScript,
> PostgreSQL, and AWS (Lambda, S3, DynamoDB).

## Trade-offs

| Gain                              | Cost                                   |
| --------------------------------- | -------------------------------------- |
| Higher parse reliability          | Loses personality and voice            |
| Better keyword matching           | Can feel generic or template-driven    |
| Passes automated screening        | May not stand out to human reviewers   |
| Works across multiple ATS systems | Requires tailoring per job description |
