## 6. Experience Section Optimization Tips

### General Principles

1. **Use reverse chronological order** - Most recent first
2. **Lead with achievements, not responsibilities** - Results over duties
3. **Quantify everything possible** - Numbers create credibility
4. **Include keywords naturally** - Technical terms in context
5. **Use bullet points** - Easier to scan than paragraphs
6. **Apply CAR/STAR framework** - Challenge, Action, Result

### Quantification Framework

For each role, try to include metrics around:

- **Scale:** Users served, team size managed, codebase scope
- **Performance:** Speed improvements, load time reductions
- **Business Impact:** Revenue influence, user engagement
- **Efficiency:** Development velocity, time savings

### Sample Experience Optimizations

**Meta/Facebook AR/VR Example:**

```
Principal UI Engineer | Meta Reality Labs
[Dates]

Led frontend architecture for AR/VR experiences across Meta's Reality Labs division:

Technologies: React, TypeScript, GraphQL, Relay, Flow, VR/AR platforms
```

## Appendix A: LinkedIn Algorithm Insights (2024-2025)

### Key Algorithm Changes

1. **Relevance Over Recency** (June 2025)
   - Algorithm now surfaces older relevant content
   - Expertise signals matter more than posting frequency

2. **AI-Assisted Recruiter Search**
   - Natural language queries are being interpreted
   - Skills relationships are being inferred
   - "Likelihood of Interest" indicator ranks candidates

3. **Content Performance Factors**
   - Dwell time (how long people read your content)
   - Engagement quality over quantity
   - First-degree connection engagement matters most

### Profile Ranking Factors for Recruiter Search

1. **Keyword Match** - Direct match between search terms and profile content
2. **Profile Completeness** - More complete profiles rank higher
3. **Connection Strength** - Mutual connections boost visibility
4. **Engagement Level** - Active profiles rank higher
5. **Skill Endorsements** - Validated skills improve ranking
6. **Premium Status** - Premium members may have slight visibility advantage
